ossia-prism 2.1.0+prism.9
Max package ossia (libossia 2.1.0) with the object ossia.v8connector,
which lets a v8 or v8ui script declare its own parameters.
Julien Bayle, PRISM (CNRS), https://www.prism.cnrs.fr/

The documentation is the README of the repository:
https://gitlab.prism.cnrs.fr/labo/outils/libossia
installation, update, declaring your own parameters, reference of the
object and of its helper, limits and troubleshooting.

In Max: right click on ossia.v8connector > Open Help; Extras menu >
ossia-prism examples.
